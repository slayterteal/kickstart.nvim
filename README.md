# Slayter's Neovim Config!

Based off of the [Kickstart](https://github.com/nvim-lua/kickstart.nvim) project. 

# Things to Install

> Ideally this will include a blend of windows and linux install instructions.

- Lua (and Luarocks the Lua Package Manager)
  - `choco install lua`
  - `choco install luarocks`
  - This will also install the needed C++ tooling(?)
<!-- - [Lua for Windows](https://github.com/rjpcomputing/luaforwindows)

- Git
- Ripgrep
  - `choco install ripgrep`
- fd
  - a plugin to find elements on the filesystem
  - [pre-build binaries](https://github.com/sharkdp/fd/releases)
  - `choco install fd`
  - `winget install sharkdp.fd`
- LazyGit - CLI Git manager
  - [install](https://github.com/jesseduffield/lazygit/releases)
    - If you need to use the pre-built binary you'll have to 
  - `choco install lazygit`
